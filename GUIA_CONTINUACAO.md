# ESTATÍSTICAS 15ª BPM — pacote de continuidade

Este pacote contém o código-fonte do aplicativo, os arquivos do instalador, os recursos visuais e os instaladores já gerados.

## No novo computador

1. Extraia este arquivo ZIP em uma pasta de trabalho.
2. Instale o .NET 8 SDK e o Inno Setup 6.
3. Abra `Estatisticas15BPM/Estatisticas15BPM.csproj` no Visual Studio 2022 ou no editor de sua preferência.
4. Para gerar uma nova versão, publique o projeto para Windows 64 bits e compile `installer/Estatisticas15BPM.iss` no Inno Setup.

## Dados do sistema

Os dados reais não acompanham este pacote. No computador atual, use a opção de exportar backup `.bkp15` dentro do sistema. No novo computador, instale o aplicativo e importe esse backup.

Não copie o banco em uso enquanto o aplicativo estiver aberto.
